Enterprise PowerShell Command Center

Battle-tested, copyable one-liners and automation scripts structured for Tier-2/3 SysAdmins. Separated cleanly into technical annotations and executable code blocks.

1. Technical Annotation (Parameter Breakdown)

Diagnose network-layer and DNS connectivity using native PowerShell cmdlets without relying on legacy Telnet or third-party tools:

  • Test-NetConnection -ComputerName ... -Port 443: Performs a 3-way TCP SYN/ACK handshake to Microsoft 365 endpoints, validating firewall rules and NAT gateway egress.
  • Clear-DnsClientCache: Purges the local DNS resolver cache on the workstation to clear stale or poisoned DNS records.
  • Resolve-DnsName -Name ... -Type A -DnsOnly: Queries authoritative A records directly from the DNS server, bypassing the local hosts file.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Test-NetConnection -ComputerName "login.microsoftonline.com" -Port 443
Clear-DnsClientCache
Resolve-DnsName -Name "login.microsoftonline.com" -Type A -DnsOnly
2. Technical Annotation (Parameter Breakdown)

Administer Active Directory Domain Services (AD DS) user accounts rapidly without opening the cumbersome ADAC GUI interface:

  • Search-ADAccount -LockedOut: Scans the entire domain and returns all user accounts locked out due to exceeding the bad-password GPO threshold.
  • Unlock-ADAccount -Identity "username": Instantly unlocks the specified user account without requiring a password reset.
  • Get-ADUser ... -Properties BadPwdCount: Audits the detailed bad-password count and the timestamp of the most recent failed authentication attempt.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Search-ADAccount -LockedOut | Select-Object Name, SamAccountName
Unlock-ADAccount -Identity "jdoe"
Get-ADUser -Identity "jdoe" -Properties BadPwdCount, badPasswordTime, LockedOut | Select-Object Name, BadPwdCount, badPasswordTime, LockedOut
3. Technical Annotation (Parameter Breakdown)

Repair Blue Screen of Death (BSOD) errors, fix corrupted Windows system files, and automatically update all installed applications:

  • DISM /Online /Cleanup-Image /RestoreHealth: Repairs the WinSxS component store directly from Microsoft's Windows Update servers.
  • sfc /scannow: Scans all protected system files and automatically replaces corrupted DLL/SYS files with clean copies.
  • winget upgrade --all --include-unknown: Upgrades all installed software on the machine to the latest version automatically.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
winget upgrade --all --include-unknown
4. Technical Annotation (Parameter Breakdown)

Diagnose the Hybrid Azure AD Join enrollment state, TPM certificate binding, and Microsoft Intune management agent status:

  • dsregcmd /status: The standard command to inspect AzureAdJoined, DomainJoined, and TPM Primary Refresh Token (PRT) status on the local machine.
  • dsregcmd /debug /leave: Resets the Cloud Identity enrollment state if the device has a broken authentication certificate with Entra ID.
  • Get-Service IntuneManagementExtension: Checks the operational status of the Microsoft Intune management agent service on the workstation.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
dsregcmd /status
Get-Service -Name "IntuneManagementExtension" | Select-Object Name, Status, StartType
Get-WinEvent -LogName "Microsoft-Windows-DeviceManagement-Enterprise-Diagnostics-Provider/Admin" -MaxEvents 10 | Select-Object TimeCreated, Id, Message
5. Technical Annotation (Parameter Breakdown)

Automatically reclaim disk space on drive C:, delete junk files, and identify oversized files causing low disk space alerts:

  • Get-ChildItem -Path C:\ ... -Length -gt 1GB: Deep-scans all files exceeding 1GB in size on the local drive and lists them sorted by size.
  • Clear-RecycleBin -Force: Permanently empties the Recycle Bin across all drive partitions without any confirmation prompt.
  • Remove-Item $env:TEMP\*: Cleans all temporary files belonging to the currently logged-on user session.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Get-ChildItem -Path C:\ -Recurse -File -ErrorAction SilentlyContinue | Where-Object { $_.Length -gt 1GB } | Select-Object FullName, @{Name="SizeGB"; Expression={[math]::Round($_.Length/1GB, 2)}} | Sort-Object SizeGB -Descending | Select-Object -First 10
Clear-RecycleBin -Force -ErrorAction SilentlyContinue
Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
6. Technical Annotation (Parameter Breakdown)

Audit network port security, detect malware or unauthorized services opening listening sockets on the endpoint:

  • Get-NetTCPConnection -State Listen: Enumerates all open TCP listening ports on the local machine with their addresses and owning processes.
  • Get-Process -Id $_.OwningProcess: Automatically maps the port's owning PID to its executable process name for instant threat identification.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Get-NetTCPConnection -State Listen | Select-Object LocalAddress, LocalPort, OwningProcess, @{Name="ProcessName"; Expression={(Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue).ProcessName}} | Sort-Object LocalPort | Format-Table -AutoSize
7. Technical Annotation (Parameter Breakdown)

Troubleshoot Windows Server Update Services (WSUS) synchronization failures and optimize the IIS Application Pool settings:

  • recycling.periodicRestart.privateMemory = 0: Removes the default 1.8GB memory limit from the IIS WsusPool to prevent HTTP 503 Service Unavailable errors during heavy catalog synchronization.
  • wsusutil.exe postinstall /servicing: Re-runs the WSUS configuration and database schema assignment process after installation or repair.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Import-Module WebAdministration
Set-ItemProperty -Path "IIS:\AppPools\WsusPool" -Name "recycling.periodicRestart.privateMemory" -Value 0
Restart-WebAppPool -Name "WsusPool"
& "C:\Program Files\Update Services\Tools\wsusutil.exe" postinstall /servicing
