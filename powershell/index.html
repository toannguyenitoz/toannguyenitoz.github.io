1. Chú Thích Kỹ Thuật (Parameter Breakdown)

Chẩn đoán kết nối tầng mạng và DNS bằng các lệnh PowerShell gốc không phụ thuộc vào công cụ Telnet của bên thứ ba:

  • Test-NetConnection -ComputerName ... -Port 443: Kiểm tra bắt tay 3 bước TCP SYN/ACK đến máy chủ Microsoft 365, xác thực firewall và NAT gateway.
  • Clear-DnsClientCache: Xóa sạch bộ đệm DNS cục bộ của máy trạm khi xảy ra hiện tượng Stale IP hoặc DNS Poisoning.
  • Resolve-DnsName -Name ... -Type A -DnsOnly: Truy vấn trực tiếp bản ghi A có thẩm quyền từ máy chủ DNS mà không qua file hosts.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Test-NetConnection -ComputerName "login.microsoftonline.com" -Port 443
Clear-DnsClientCache
Resolve-DnsName -Name "login.microsoftonline.com" -Type A -DnsOnly
2. Chú Thích Kỹ Thuật (Parameter Breakdown)

Quản trị tài khoản Active Directory Domain Services (AD DS) nhanh chóng mà không cần mở giao diện cồng kềnh ADAC:

  • Search-ADAccount -LockedOut: Quét toàn bộ domain và trả về danh sách các user bị khóa do nhập sai mật khẩu quá giới hạn GPO.
  • Unlock-ADAccount -Identity "username": Mở khóa tức thì cho người dùng chỉ trong 1 giây.
  • Get-ADUser ... -Properties BadPwdCount: Điều tra chi tiết số lần gõ sai pass và thời điểm xác thực thất bại gần nhất.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Search-ADAccount -LockedOut | Select-Object Name, SamAccountName
Unlock-ADAccount -Identity "jdoe"
Get-ADUser -Identity "jdoe" -Properties BadPwdCount, badPasswordTime, LockedOut | Select-Object Name, BadPwdCount, badPasswordTime, LockedOut
3. Chú Thích Kỹ Thuật (Parameter Breakdown)

Khắc phục lỗi màn hình xanh (BSOD), file hệ thống Windows bị hỏng và cập nhật ứng dụng tự động:

  • DISM /Online /Cleanup-Image /RestoreHealth: Sửa chữa kho lưu trữ thành phần WinSxS trực tiếp từ máy chủ Windows Update của Microsoft.
  • sfc /scannow: Quét và tự động thay thế các file DLL/SYS hệ thống bị hỏng bằng bản sao nguyên vẹn.
  • winget upgrade --all --include-unknown: Nâng cấp toàn bộ phần mềm trên máy tính lên phiên bản mới nhất một cách tự động.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
winget upgrade --all --include-unknown
4. Chú Thích Kỹ Thuật (Parameter Breakdown)

Chẩn đoán trạng thái gia nhập Hybrid Azure AD Join, chứng chỉ TPM và Intune Enrollment:

  • dsregcmd /status: Lệnh chuẩn kiểm tra trạng thái AzureAdJoined, DomainJoined và TPM Primary Refresh Token (PRT).
  • dsregcmd /debug /leave: Reset trạng thái đăng ký Cloud Identity nếu thiết bị bị lỗi chứng chỉ xác thực với Entra ID.
  • Get-Service IntuneManagementExtension: Kiểm tra trạng thái hoạt động của agent quản lý Microsoft Intune trên máy trạm.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
dsregcmd /status
Get-Service -Name "IntuneManagementExtension" | Select-Object Name, Status, StartType
Get-WinEvent -LogName "Microsoft-Windows-DeviceManagement-Enterprise-Diagnostics-Provider/Admin" -MaxEvents 10 | Select-Object TimeCreated, Id, Message
5. Chú Thích Kỹ Thuật (Parameter Breakdown)

Tự động dọn dẹp dung lượng ổ cứng, xóa file rác và quét các file dung lượng lớn gây đầy ổ C:

  • Get-ChildItem -Path C:\ ... -Length -gt 1GB: Truy quét các tệp tin phình to vượt quá 1GB trong máy tính.
  • Clear-RecycleBin -Force: Làm rỗng Thùng rác của toàn bộ các phân vùng ổ đĩa mà không hỏi xác nhận.
  • Remove-Item $env:TEMP\*: Dọn sạch file tạm (Temporary files) của người dùng đang đăng nhập.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Get-ChildItem -Path C:\ -Recurse -File -ErrorAction SilentlyContinue | Where-Object { $_.Length -gt 1GB } | Select-Object FullName, @{Name="SizeGB"; Expression={[math]::Round($_.Length/1GB, 2)}} | Sort-Object SizeGB -Descending | Select-Object -First 10
Clear-RecycleBin -Force -ErrorAction SilentlyContinue
Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
6. Chú Thích Kỹ Thuật (Parameter Breakdown)

Điều tra bảo mật cổng mạng, phát hiện phần mềm độc hại đang mở socket lắng nghe trên endpoint:

  • Get-NetTCPConnection -State Listen: Liệt kê tất cả cổng TCP đang mở trên máy.
  • Get-Process -Id $_.OwningProcess: Tự động ánh xạ số hiệu PID của cổng sang tên tiến trình thực thi (Process Name).
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Get-NetTCPConnection -State Listen | Select-Object LocalAddress, LocalPort, OwningProcess, @{Name="ProcessName"; Expression={(Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue).ProcessName}} | Sort-Object LocalPort | Format-Table -AutoSize
7. Chú Thích Kỹ Thuật (Parameter Breakdown)

Khắc phục sự cố Windows Server Update Services (WSUS) và tối ưu hóa IIS Application Pool:

  • recycling.periodicRestart.privateMemory = 0: Gỡ bỏ giới hạn 1.8GB mặc định của IIS WsusPool để tránh lỗi HTTP 503 Service Unavailable khi đồng bộ catalog nặng.
  • wsusutil.exe postinstall /servicing: Chạy lại tiến trình cấu hình và gán database schema của WSUS sau khi cài đặt.
⚡ EXECUTABLE POWERSHELL (READY TO RUN) 
Import-Module WebAdministration
Set-ItemProperty -Path "IIS:\AppPools\WsusPool" -Name "recycling.periodicRestart.privateMemory" -Value 0
Restart-WebAppPool -Name "WsusPool"
& "C:\Program Files\Update Services\Tools\wsusutil.exe" postinstall /servicing
