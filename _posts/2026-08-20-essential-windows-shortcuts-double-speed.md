## Core Shortcuts & Action Summary

| Shortcut Key | Action / Function | Enterprise Workflow Impact |
| :--- | :--- | :--- |
| `<kbd>Win + V</kbd>` | **Clipboard History** | View & paste from last 25 copied items. Never lose text again. |
| `<kbd>Win + Shift + S</kbd>` | **Smart Snip + OCR** | Crop screen, then extract text from the screenshot image. |
| `<kbd>Ctrl + Shift + Esc</kbd>` | **Direct Task Manager** | Instantly open Task Manager. Skip the Ctrl+Alt+Delete screen. |
| `<kbd>Win + D</kbd>` | **Desktop Peek / Restore** | Minimize all windows. Press again to restore them all back. |
| `<kbd>Win + L</kbd>` | **Lock Workstation** | Lock screen in 0.1 seconds when stepping away from desk. |

## 💡 20+ Years Enterprise IT Pro-Tip

> **Toan's Pro-Tip:** Pin your most-used text templates (email signatures, ticket notes, server IPs) inside Win + V clipboard — they stay pinned permanently.
