## Core Shortcuts & Action Summary

| Shortcut Key | Action / Function | Enterprise Workflow Impact |
| :--- | :--- | :--- |
| `<kbd>Win + Z</kbd>` | **Open Snap Layouts** | Pops up the visual grid picker on any active window. |
| `<kbd>Win + Left/Right</kbd>` | **Half Screen Snap** | Snaps active window to left or right 50% screen half. |
| `<kbd>Win + Up Arrow</kbd>` | **Maximize / Top Snap** | Maximizes window or snaps to top-half quarter. |
| `<kbd>Win + Down Arrow</kbd>` | **Minimize Window** | Restores window size or minimizes down to taskbar. |
| `<kbd>Snap Groups (Alt+Tab)</kbd>` | **Group Persistence** | Windows remembers paired snap groups when switching tasks. |

---

## 💡 20+ Years Enterprise IT Pro-Tip

> **Toan's Pro-Tip:** Hover your mouse cursor over the Maximize button of any window to visually select 2, 3, or 4-window grid layouts.
