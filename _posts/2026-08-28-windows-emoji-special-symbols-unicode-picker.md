## Core Shortcuts & Action Summary

| Shortcut Key | Action / Function | Enterprise Workflow Impact |
| :--- | :--- | :--- |
| `<kbd>Win + . (Period)</kbd>` | **Open Symbols Panel** | Launches the comprehensive Windows Unicode & Symbol picker. |
| `<kbd>Math & Greek Tab</kbd>` | **Scientific Notation** | Insert Ω, µ, ±, ≤, ≥, π, ∑ without Alt codes. |
| `<kbd>Currency Tab</kbd>` | **Global Currency** | Insert €, £, ¥, ₩, ₹, ₫ symbols with 1 click. |
| `<kbd>Kaomoji & Emote</kbd>` | **Expressive Text** | Insert text faces (╯°□°)╯ and standard colored emojis. |
| `<kbd>Clipboard History</kbd>` | **Direct Tab Switch** | Switch between Symbols and Win+V Clipboard History inside same UI. |
