>_ Quick PowerShell Toolbox

Tập hợp các lệnh PowerShell xử lý nhanh các tác vụ quản trị hàng ngày chỉ với 1 cú click.

Windows Terminal — Administrator: Windows PowerShell

Kiểm tra kết nối cổng dịch vụ (Port Test), tra cứu nhanh bản ghi DNS và xóa cache DNS máy trạm:

PS C:\> # Kiểm tra kết nối TCP Port 443 đến máy chủ & xóa bộ nhớ cache DNS Test-NetConnection -ComputerName login.microsoftonline.com -Port 443 Clear-DnsClientCache Resolve-DnsName -Name outlook.office365.com -Type A

Mở khóa tài khoản nhân viên bị khóa mật khẩu (Locked Out) và kiểm tra tình trạng tài khoản:

PS C:\> # Tìm tài khoản bị khóa và thực hiện mở khóa nhanh Search-ADAccount -LockedOut | Select-Object SamAccountName, Name Unlock-ADAccount -Identity "username" Get-ADUser -Identity "username" -Properties PasswordLastSet, LockedOut, Enabled

Chạy công cụ quét sửa lỗi tệp tin hệ thống (SFC / DISM) và cập nhật tất cả phần mềm qua WinGet:

PS C:\> # Sửa chữa kho lưu trữ tệp tin hệ điều hành và nâng cấp phần mềm sfc /scannow DISM.exe /Online /Cleanup-image /Restorehealth winget upgrade --all --include-unknown

Kiểm tra trạng thái tham gia miền Microsoft Entra ID (Azure AD Join) và Token máy trạm:

PS C:\> # Kiểm tra kết quả gia nhập Azure AD & Tình trạng thiết bị Intune dsregcmd /status Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Enrollments\* | Select-Object ProviderID, UPN
