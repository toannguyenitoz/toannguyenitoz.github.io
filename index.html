>_ Quick PowerShell Toolbox

Production-ready one-liners and administrative routines designed for 1-click execution.

Windows Terminal — Administrator: Windows PowerShell

Inspect TCP port handshake, resolve authoritative DNS records, and flush local resolver cache:

PS C:\> # Test TCP Port 443 handshake to Microsoft 365 & flush DNS cache Test-NetConnection -ComputerName login.microsoftonline.com -Port 443 -InformationLevel Detailed Clear-DnsClientCache Resolve-DnsName -Name outlook.office365.com -Type A

Remediate locked-out user accounts, audit bad password attempts, and query account flags:

PS C:\> # Locate and unlock domain accounts experiencing repeated lockouts Search-ADAccount -LockedOut | Select-Object SamAccountName, Name, LastLogonDate Unlock-ADAccount -Identity "username" Get-ADUser -Identity "username" -Properties BadLogonCount, BadPasswordTime, LockedOut, PasswordLastSet

Execute Windows servicing component store repair, SFC system integrity scan, and bulk app upgrade:

PS C:\> # Repair Windows Component Store, verify system DLLs, and upgrade software DISM.exe /Online /Cleanup-Image /RestoreHealth sfc /scannow winget upgrade --all --include-unknown

Verify Microsoft Entra ID (Azure AD Join) device enrollment, PRT token health, and Intune enrollment:

PS C:\> # Check Azure AD join state, Primary Refresh Token (PRT), and MDM enrollment dsregcmd /status Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Enrollments\* | Select-Object ProviderID, UPN
