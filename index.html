Comment & Parameter Breakdown

Validates end-to-end TCP egress connectivity to Microsoft 365 cloud endpoints, flushes corrupted local DNS resolver caches, and queries authoritative DNS records directly.

  • Test-NetConnection Performs a 3-way TCP socket handshake against login.microsoftonline.com:443. -InformationLevel Detailed returns round-trip latency and routing interfaces.
  • Clear-DnsClientCache Purges all cached DNS name resolution entries locally to resolve poisoned or stale records.
  • Resolve-DnsName Performs a direct authoritative lookup for IPv4 Type A records on outlook.office365.com.
Executable Commands (Ready to Run) 
Test-NetConnection -ComputerName login.microsoftonline.com -Port 443 -InformationLevel Detailed
Clear-DnsClientCache
Resolve-DnsName -Name outlook.office365.com -Type A
🏢 Domain Controller Kerberos KDC
──(Event 4740)──►
🔒 Account Lockout BadLogonCount > 5
──(Unlock)──►
🔓 Active Token Access Restored
Status: Remediated
Comment & Parameter Breakdown

Triages domain user account lockouts in Active Directory, immediately clears the lockout flag without password resets, and audits authentication failure metrics.

  • Search-ADAccount -LockedOut Enumerates all accounts currently locked across the domain partition with their last logon timestamp.
  • Unlock-ADAccount Unlocks the specified user identity by clearing the lockout attribute on the Domain Controller.
  • Get-ADUser Inspects BadLogonCount, BadPasswordTime, and PasswordLastSet to detect credential stuffing or cached credentials.
Executable Commands (Ready to Run) 
Search-ADAccount -LockedOut | Select-Object SamAccountName, Name, LastLogonDate
Unlock-ADAccount -Identity "username"
Get-ADUser -Identity "username" -Properties BadLogonCount, BadPasswordTime, LockedOut, PasswordLastSet

Repairs the Windows Component Store (WinSxS), scans and restores protected system binaries, and performs silent bulk software updates across all installed enterprise packages.

  • DISM /RestoreHealth Scans and fixes corrupted files in the Windows Component Store using Windows Update as the clean source.

sfc /scannow
winget upgrade --all --include-unknown

💽 Drive C:\ Volume Low Disk Space Alert
──(Deep Traverse)──►
🔍 Top 10 File Hogs Sorted by Size (>1GB)
──(Reclaim)──►
♻️ Temp Cache Purged Free Space Restored
Status: Storage Optimized
Comment & Parameter Breakdown

Recursively traverses drive C: while suppressing access-denied errors to locate the top 10 largest files exceeding 1 GB, and empties the Recycle Bin without confirmation prompts.

  • Get-ChildItem -Recurse Deep scans files over 1GB, sorts descending by byte length, and prints size in GB alongside filepath.
  • Clear-RecycleBin -Force Empties all deleted items across local drives silently without GUI popup confirmation.
Executable Commands (Ready to Run) 
Get-ChildItem -Path C:\ -Recurse -File -ErrorAction SilentlyContinue | Where-Object { $_.Length -gt 1GB } | Sort-Object Length -Descending | Select-Object -First 10 Name, @{Name="SizeGB";Expression={[math]::Round($_.Length/1GB,2)}}, Directory
Clear-RecycleBin -Force -ErrorAction SilentlyContinue
🔌 TCP Sockets State: LISTENING
──(NetTCPConnection)──►
🏷️ Owning PID Process Identifier
──(Task Mapping)──►
🛡️ Process Name Threat Triage Complete
Status: Ports Audited
Comment & Parameter Breakdown

Queries all open listening TCP ports, correlates each socket's Owning PID directly against the operating system process table, and resolves the executable process name.

  • Get-NetTCPConnection -State Listen Enumerates every TCP socket actively bound to listening mode on local network interfaces.
  • Get-Process -Id $_.OwningProcess Resolves the owning Process ID (PID) to its running process name (e.g. svchost.exe, node.exe) for instant port conflict identification.
Executable Commands (Ready to Run) 
Get-NetTCPConnection -State Listen | Select-Object LocalAddress, LocalPort, OwningProcess, @{Name="ProcessName";Expression={(Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue).Name}} | Sort-Object LocalPort | Format-Table -AutoSize
