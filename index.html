Parameter Breakdown

Performs 3-way TCP socket handshake to Microsoft 365 on port 443 and flushes local DNS cache.

⚡ Executable Cmdlet 
Test-NetConnection -ComputerName login.microsoftonline.com -Port 443
Clear-DnsClientCache
Resolve-DnsName -Name outlook.office365.com -Type A
Parameter Breakdown

Enumerates locked accounts across domain and unlocks specific user identity immediately.

⚡ Executable Cmdlet 
Search-ADAccount -LockedOut | Select-Object SamAccountName, Name
Unlock-ADAccount -Identity "username"
Get-ADUser -Identity "username" -Properties BadPwdCount
Parameter Breakdown

Repairs WinSxS component store from Windows Update, runs SFC integrity scan, and upgrades apps.

⚡ Executable Cmdlet 
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
winget upgrade --all --include-unknown
Parameter Breakdown

Inspects Hybrid Azure AD Join state, SSO PRT token status, and restarts Intune management agent.

⚡ Executable Cmdlet 
dsregcmd /status
Get-Service -Name IntuneManagementExtension
Restart-Service IntuneManagementExtension -Force
Parameter Breakdown

Deep scans files over 1GB on drive C:, empties the Recycle Bin silently, and purges user temp files.

⚡ Executable Cmdlet 
Get-ChildItem -Path C:\ -Recurse -File -ErrorAction SilentlyContinue | Where-Object { $_.Length -gt 1GB } | Select-Object -First 10 FullName, Length
Clear-RecycleBin -Force -ErrorAction SilentlyContinue
Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
Parameter Breakdown

Lists listening TCP ports and correlates socket OwningProcess ID directly to executable name.

⚡ Executable Cmdlet 
Get-NetTCPConnection -State Listen | Select-Object LocalAddress, LocalPort, OwningProcess, @{Name="ProcessName"; Expression={(Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue).ProcessName}} | Format-Table -AutoSize
